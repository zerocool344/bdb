Daily Consensus Desk - Autonomous Architecture

Dynamic Live Screener: This dashboard is now fully autonomous! It no longer requires manual research or hardcoded lists. Clicking the "Refresh Live Data" button triggers an on-demand scrape of Yahoo Finance data for the predefined watchlist.

How It Works

The Streamlit application (app.py) operates as follows:

  1. The Watchlist: The app iterates through a master list of tickers (e.g. MSFT, AAPL, GOOGL).
  2. Data Fetching: It securely connects to Yahoo Finance public endpoints to pull the targetMeanPrice, currentPrice, and analyst recommendationKey (e.g., Strong Buy).
  3. Automatic Classification:
    • FAR (Deep Value): Target upside is greater than 25%.
    • NEAR (Growth/Value): Target upside is between 10% and 25%.
    • WATCH: Target upside is less than 10%.

Security & Privacy

Because the app utilizes the yfinance library to aggregate public consensus ratings, it requires zero API keys and does not have access to any personal financial data or Google Account credentials. All deployments to Streamlit Community Cloud are secured via SSO.

Modifying the Watchlist

To track new stocks, simply add the ticker symbol to the WATCHLIST array at the top of app.py, commit the change, and push to GitHub. The live dashboard will adapt instantly.
